# Raanana Jazz Festival

Website for פסטיבל הג׳אז רעננה – served at https://raananajazzfestival.com via GitHub Pages.

- `index.html` – the whole site. Lineup, featured cards, teachers and photo grid are data arrays in the `<script>` at the bottom.
- `images/` – photos and artwork.
- `CNAME` – custom domain for GitHub Pages.
