# Raanana Jazz Festival

Website for פסטיבל הג׳אז רעננה – served at https://raananajazzfestival.com via GitHub Pages.

## Before launch: hidden site + coming-soon page
Until launch, the main address shows a "coming soon" page and the real site lives in one hidden folder (the folder whose name starts with `preview-`). Only people who are given that link can reach the site, and its pages carry `noindex`, so search engines skip them.

- The folder name is the secret path. It is written nowhere else: `build_pages.py` finds the folder by itself (it is the one holding `assets/site.js`), so neither this file nor the build script gives it away. Keep it out of anything published at the root.
- The coming-soon page (`index.html` and `404.html` at the root) is generated by `build_pages.py`. It takes the dates and venue from `data.js` and uses its own copies of the logo, lettering and font in `soon/`, so it never links into the hidden folder. Old addresses (`/lineup.html`, `/en/` …) land on it too.
- **Rename the secret path:** `git mv preview-xxxx new-name`, then run `python3 build_pages.py`.
- **Launch (site goes public at the main address):** run `python3 build_pages.py --launch`, then commit and push. It removes the coming-soon page and `soon/`, moves the pages, `en/`, `assets/` and `images/` from the hidden folder back to the root, and rebuilds them as the public site (normal `404.html`, no `noindex`).

## Languages
Hebrew pages live at the site root, English pages under `en/`. Both are generated by `build_pages.py`; the language button in the top bar, menu and footer jumps to the same page in the other language. Links work in either location: the build writes every page as if it sat at the domain root and then moves its links into the folder, and `site.js` reads its own folder from its URL.

## Editing
All paths below are inside the site folder (the hidden folder before launch, the root after).
- **Content** (shows, times, ticket links, teachers, photos, partners, contact email): `assets/data.js`. Every page reads from it. English text sits next to the Hebrew in `_en` fields (`title_en`, `desc_en`, `venue_en`).
- **Menu, header, footer**: `assets/site.js`.
- **Design**: `assets/site.css`.
- **Page text/layout**: `build_pages.py` (at the repo root) holds each page's markup with Hebrew and English side by side (`t('עברית', 'English')`); run `python3 build_pages.py` to regenerate both languages and the coming-soon page.
- Images live in `images/`.
