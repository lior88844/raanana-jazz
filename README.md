# Raanana Jazz Festival

Website for פסטיבל הג׳אז רעננה – served at https://raananajazzfestival.com via GitHub Pages.

## Languages
Hebrew pages live at the root (`/`), English pages under `/en/`. Both are generated by `build_pages.py`; the language button in the top bar, menu and footer jumps to the same page in the other language.

## Pages
| Page | File |
|---|---|
| Home | `index.html` |
| Line-up (all shows + ticket links) | `lineup.html` |
| Past editions – 2025 artists | `festival-2025.html` |
| Venue – the four stages + map | `venue.html` |
| About | `about.html` |
| Workshops | `workshops.html` |
| Media / press downloads | `media.html` |
| Tickets & passes | `tickets.html` |
| Contact | `contact.html` |

## Editing
- **Content** (shows, times, ticket links, teachers, photos, partners, contact email): `assets/data.js`. Every page reads from it. English text sits next to the Hebrew in `_en` fields (`title_en`, `desc_en`, `venue_en`).
- **Menu, header, footer**: `assets/site.js`.
- **Design**: `assets/site.css`.
- **Page text/layout**: `build_pages.py` holds each page's markup with Hebrew and English side by side (`t('עברית', 'English')`); run `python3 build_pages.py` to regenerate both languages.
- Images live in `images/`.
